# 合规义务台账

行政事项的口径一律按这张表走，不要凭印象。每条的「起算日」「办理时限」
「经办提前量」都是从批复件、许可证或主管部门通知上抄下来的原文。

计算口径（三年前找律师核过，之后没变）：

- **截止日** = 起算日 + 办理时限，时限按自然日算，含首日不含尾日之外的特例一律没有。
- **最早动手日** = 截止日 − 经办提前量。提前量是材料准备、盖章、邮寄在路上的时间，
  不是缓冲——压到提前量之后才动手，基本就赶不上了。
