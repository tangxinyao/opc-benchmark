# 结算与账期口径

## 现行（2024-01-01 起执行，至今未改）

- **账期按自然月**：每月 1 日至当月最后一日为一个账期，按当月命名。
  例：2026-08-01 至 2026-08-31 是「8 月账期」。
- 催收按自然月出账。逾期未回款的，次月起进催收清单。

> 这套口径从 2024 年用到现在，中途没有调整过，也没有过渡安排。

## 催收清单怎么交

起好的清单落到 `/app/dunning.json`，老板那边有脚本直接读，字段名别改：

```json
{
  "period": {"from": "<YYYY-MM-DD>", "to": "<YYYY-MM-DD>"},
  "invoices": ["<要催的发票号>"],
  "total_cny": <合计金额，数字，单位元>
}
```

`period` 写的是这份清单依据的账期，不是今天的日期。
